## 🧭 What this hub is

Learn is the home of the Electrum-PPC how-to guides. Electrum-PPC is a desktop wallet for Peercoin (PPC) that runs on Windows, macOS and Linux, and it is built on Electrum as an independent project. Every guide here answers one practical question that people ask when they install the wallet, protect access to their coins, move a payment, or try to understand why something on screen looks different from what they expected. The guides are written in plain language, with numbered steps you can follow at your own pace and short explanations of why each step matters.

The guides are meant for anyone using Electrum-PPC, from a first-time Peercoin holder installing a wallet for the first time to someone who has used desktop wallets for years and wants a quick checklist before restoring a backup on a new computer. You do not need to know how the Peercoin network works internally to use them. Where a topic touches something that has not been confirmed for this wallet, such as offline signing, hardware devices, multisig or minting, the guide says so clearly and offers general guidance instead of promising a feature.

## 🗂️ How the guides are grouped

The guides are organised into seven groups, listed below in the order most people need them. Install and download covers getting the right package for your computer and checking it before you run it. Backup and recovery explains how to protect wallet access with a seed phrase and how to restore it later. Sync and connection helps when the balance or history looks stale. Transactions walks through sending, receiving, fees and pending payments. Security collects habits that keep phishing and fake support at a distance. Advanced features describes what to check before relying on more specialised workflows, and Peercoin basics and comparisons gives background on the coin and on how this wallet differs from a full node.

## 🔍 How to verify a download

Before you run any installer, compare its SHA-256 value with the value published on the release page. On Windows, open PowerShell in your downloads folder and run `Get-FileHash` with the SHA256 algorithm. On macOS, use `shasum -a 256` in Terminal. On Linux, use `sha256sum`. The result must match the published value exactly, character for character. If it does not match, delete the file and download it again from the release page, and never run a copy that came from a message, an advertisement or an unfamiliar site.
